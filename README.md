# Archive
This project is now archived. With the release of Bevy 0.17, its built-in solari plugin provides official hardware-accelerated ray tracing, making this two-bounce, compute shader-based implementation obsolete.

For those interested in compute shader-based ray tracing, you can refer to the maltz branch, which is compatible with bevy 0.13.
